# Theoretical Question Generator with Answers

## Description

The **Theoretical Question Generator with Answers** is a simple project that presents users with a random theoretical question and then reveals the corresponding answer. It is designed as a learning tool to help reinforce knowledge through self-testing.

## Features

- 🎲 Generates a random theoretical question.
- ✅ Displays the correct answer.
- 📚 Useful for learning and reviewing concepts.

## Use Cases

- Self-study and revision.
- Practice theoretical questions.
- Reinforce learning through active recall.

## Getting Started

1. Run the application.
2. Receive a random theoretical question.
3. Think of your answer.
4. Reveal the correct answer and compare it with your own.

## Future Improvements

- Add categories for different subjects.
- Track answered questions.
- Allow users to add custom questions and answers.
- Implement difficulty levels.
